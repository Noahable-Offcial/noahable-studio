# Noahable Studio

Official website for Noahable Studio — a black, minimalist home for games, technology, NGPT and studio opportunities.

## Pages
- Home: /
- Games: /games
- Our Work: /work
- Who We Are: /about
- Introducing NGPT: /ngpt
- Join Us: /join

## Run locally
This is a static website. Open index.html in a browser, or use any static local server.

## Deploy to Vercel
Import this repository into Vercel. No build command is required; the site is static. The Vercel project should use this repository as its Git source and deploy the main branch.

## Customize
- Edit page copy and external links in index.html.
- Edit the visual design in styles.css.
- Edit navigation behavior in app.js.

The Join Us page currently links to the Google Form URL supplied for the project. Check the form's responder link and sharing settings before launch.
